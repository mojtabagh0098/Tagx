# Code 87 v1 — ربات مدیریت و تگ تلگرام

ربات رایگان برای مدیریت مدیران مجاز گروه و تگ‌کردن مالک/مدیران واقعی گروه یا اعضای شناخته‌شده. پیاده‌سازی با Python و `python-telegram-bot` است و اطلاعات را به‌صورت محلی در فایل JSON نگه می‌دارد.

> **امنیت توکن:** توکن ربات در متن درخواست افشا شده است؛ آن را افشاشده فرض کنید. پیش از اجرا، توکن قبلی را از طریق [@BotFather](https://t.me/BotFather) باطل (revoke) و یک توکن تازه بسازید. توکن را در کد یا Git قرار ندهید؛ فقط در فایل محلی `.env` بگذارید.

## امکانات

- نام برنامه: **Code 87 v1**
- مالک پیش‌فرض: شناسه `7365481512`؛ با `OWNER_ID` در `.env` قابل تنظیم است.
- `/panel` برای مالک:
  - در گروه: پنل انتخاب مدیران واقعی همان گروه و اعطای/لغو دسترسی `/tg`.
  - در پیوی: استعلام زنده گروه‌های ثبت‌شده؛ گروه‌هایی که ربات قطعاً از آن‌ها خارج/اخراج شده یا دیگر وجود ندارند از دیتابیس پاک می‌شوند. خطای موقت/API باعث حذف گروه نمی‌شود.
- `/tg` برای مالک و مدیران مجاز: منوی تگ مالک و مدیران واقعی گروه یا انتخاب اعضا.
- `/reset` فقط برای مالک در گروه: دسترسی‌های مدیران را پاک می‌کند و فهرست `target_users` را **حفظ** می‌کند.
- کاربران عادی و مدیران غیرمجاز نمی‌توانند از دکمه‌های پنل استفاده کنند؛ کلیک غیرمجاز با هشدار رد می‌شود.
- هر مدیر مجاز فقط پنلی را می‌بندد که خودش ساخته است؛ مالک می‌تواند پنل هر کاربری را ببندد.
- اعضا با پیام‌دادن، ورود یا خروج در حافظه گروه به‌روزرسانی می‌شوند. هر بسته تگ حداکثر پنج نفر دارد؛ برای عضو دارای username از `@username` و برای بقیه از پیوند `tg://user?id=...` استفاده می‌شود.
- نوشتن JSON به شکل اتمیک انجام می‌شود تا قطع‌شدن فرایند وسط ذخیره‌سازی، فایل اصلی را ناقص نکند.

## پیش‌نیازها

- Python **3.10 یا جدیدتر**
- یک ربات ساخته‌شده با BotFather
- اینترنت برای اتصال polling ربات به Telegram Bot API

خود Bot API و کتابخانه‌ها هزینه‌ای ندارند. اگر ربات باید ۲۴ساعته آنلاین بماند، دستگاه/میزبانی باید روشن و متصل بماند؛ روی رایانه شخصی رایگان است، ولی با خاموش‌شدن رایانه ربات هم آفلاین می‌شود. سرویس‌های میزبانی رایگان ممکن است محدودیت یا خواب خودکار داشته باشند.

## نصب روی Windows

در PowerShell یا ترمینال، وارد پوشه پروژه شوید:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

فایل `.env` را باز کنید و `BOT_TOKEN` را با **توکن تازه** جایگزین کنید. مقدار `OWNER_ID` از قبل برای مالک درخواست تنظیم شده است؛ در صورت نیاز آن را تغییر دهید.

سپس اجرا کنید:

```powershell
python bot.py
```

## نصب روی Linux یا macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
```

فایل `.env` را ویرایش کنید، توکن تازه را در `BOT_TOKEN` بگذارید و اجرا کنید:

```bash
python bot.py
```

برای توقف، `Ctrl+C` بزنید. فایل `bot_database.json` هنگام شروع/اولین تغییر کنار `bot.py` ساخته می‌شود. از این فایل نسخه پشتیبان بگیرید؛ اطلاعات گروه‌ها، مدیران مجاز و اعضا در آن است. آن را عمومی یا در Git منتشر نکنید.

## راه‌اندازی در تلگرام

1. در BotFather یک ربات بسازید، در صورت تمایل نام نمایشی آن را `Code 87 v1` بگذارید و توکن تازه را در `.env` قرار دهید.
2. ربات را به گروه اضافه و **مدیر گروه** کنید. دسترسی مدیر برای گرفتن فهرست مدیران و دریافت مطمئن پیام‌ها/رویدادهای عضویت لازم است؛ دسترسی‌های مدیریتی غیرضروری را فعال نکنید.
3. مالک در گروه `/panel` را بزند و مدیرانی را که باید اجازه استفاده از ربات داشته باشند انتخاب کند. فقط مدیران واقعی گروه در این فهرست نمایش داده می‌شوند.
4. مالک یا مدیر مجاز در گروه `/tg` را بزند و از پنل گزینه موردنظر را انتخاب کند.
5. مالک برای پاک‌کردن دسترسی‌ها در گروه `/reset` را بزند. فهرست اعضای ذخیره‌شده باقی می‌ماند.
6. مالک در پیوی ربات `/panel` را بزند تا فهرست گروه‌ها به‌صورت زنده بررسی شود.

فرمان‌ها با یا بدون `/` شناخته می‌شوند؛ برای نمونه `tg` و `/tg`. معمولاً فرمان‌های دارای `/` انتخاب مطمئن‌تری هستند. اگر تنظیم حریم خصوصی ربات در BotFather روشن باشد، Telegram ممکن است متن‌های عادی گروه را به ربات نرساند؛ مدیرکردن ربات راه لازم برای دریافت پیام‌ها و رویدادهاست.

## محدودیت مهم Telegram درباره فهرست اعضا

Telegram Bot API راهی برای دریافت یک‌جای فهرست **تمام اعضای قدیمی گروه** در اختیار ربات نمی‌گذارد. بنابراین `target_users` شامل کاربرانی است که ربات رویداد ورودشان را دریافت کرده یا پیامی از آن‌ها دیده است؛ اعضای قدیمی و ساکتی که هیچ رویدادی از آن‌ها به ربات نرسیده باشد تا پیش از اولین پیام‌شان در فهرست نیستند. خروج‌هایی که ربات دریافت کند حذف می‌شوند. برای تکمیل تدریجی فهرست، از اعضا بخواهید در گروه پیام بفرستند. این محدودیت از سمت Telegram است و با کد قابل دورزدن نیست.

## نکات امنیتی و عملیاتی

- فایل `.env` و `bot_database.json` در `.gitignore` هستند؛ این دو را در مخزن یا چت منتشر نکنید.
- در هر زمان فقط **یک نمونه** از polling این ربات را با یک فایل دیتابیس اجرا کنید.
- مدیر مجاز فقط وقتی اجازه `/tg` دارد که هم در فهرست مجاز ربات باشد و هم هنوز مدیر واقعی گروه باشد. مدیرانی که از گروه خارج شوند از دسترسی نیز حذف می‌شوند.
- پنل‌های انتخاب و وضعیت تگ موقتاً در حافظه فرایند هستند؛ پس از راه‌اندازی مجدد، پنل قدیمی منقضی می‌شود و باید `/tg` را دوباره اجرا کرد. اطلاعات اصلی گروه‌ها و اعضا در JSON باقی می‌ماند.
- این پروژه به سرویس/هوش مصنوعی پولی یا دیتابیس خارجی وابسته نیست.
